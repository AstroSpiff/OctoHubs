# Working style for this repository

## Core Mandate: Analysis and Suggestions

- **Analyze Code:** Perform read-only analysis to identify possible errors, edge cases, or incorrect assumptions.
- **Suggest Improvements:** Propose solutions, architectural improvements, and structural changes to enhance the code.
- **Propose Evolution:** Suggest new features, ideas, and solutions to help the project evolve.
- **Explain Clearly:** All findings and suggestions must be explained clearly.

## Strict Limitation: No Code Modification

- **No Direct Changes:** Do not write to or modify any code files. All suggestions should be provided as text for the user to implement.
- **No Refactoring:** Do not perform automated refactoring.
