# Contesto progetto

Questa e una web app Flask.
Backend: Python.
Frontend: HTML (Jinja templates), JavaScript, CSS.

Regole specifiche per il progetto:
- Non cambiare URL delle route, metodi HTTP o formati di risposta se non richiesto.
- Non rinominare variabili dei template se non aggiorni tutti i riferimenti.
- Non rinominare classi/id CSS o selettori JS se non aggiorni tutti i riferimenti.

Note:
- Ignora virtualenv, build artifacts, cache e dependency folders.
- Concentrati solo sui file sorgenti dell'app.
