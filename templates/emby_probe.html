Configurazione algoritmo di individuazione

ℹ️ Info: Questi parametri controllano l'algoritmo di individuazione ibrido (timestamp tracking + sliding window). Le modifiche si applicano dal prossimo scan.

Parametri Finestra Scorrevole

Default: 500 - Più alto = scan più accurato ma più lento | Range: 100-2000
Default: 90% - Es: con 500 file e 90%, si ferma quando 450 hanno mediainfo | Range: 50-100%

Parametri Timestamp Tracking

Default: 7 giorni - Range: 1-30 giorni

Condizioni di Stop

Default: 60 giorni - Range: 7-365 giorni
Default: 2000 - Range: 500-10000

📖 Come Funziona

L'algoritmo ibrido combina due strategie per trovare efficientemente i file senza mediainfo:

  • Primo scan: cerca file fino a Massimo Giorni indietro nel tempo
  • Scan successivi: cerca solo nuovi file dall'ultimo scan (con Margine di Sicurezza per evitare gap)
  • Finestra scorrevole: analizza gli ultimi Dimensione Finestra file .strm e si ferma quando la Soglia Completamento ha già mediainfo
  • Stop condizioni: si ferma anche se supera Massimo Giorni o Massimo Elementi controllati
  • Analisi intelligente: i file vengono processati dal più vecchio al più recente, così se interrompi l'analisi non perdi i file recenti (più importanti)
