TMDB (The Movie Database)

API usata per l'autocomplete nella Ricerca Indipendente.
La lingua influenza i risultati e i titoli tradotti.
Ottieni la tua API key gratuita su themoviedb.org/settings/api

MDBList

Fonte primaria per rating (IMDb, Metacritic, Rotten Tomatoes, Letterboxd). Per serie TV, calcola media Metacritic su tutte le stagioni.
Supporta rotazione automatica in caso di rate limit. Lascia vuoto per usare solo OMDb.
Ottieni una API key gratuita su mdblist.com/preferences

OMDb (Open Movie Database)

Fallback per rating quando MDBList non disponibile. Fornisce IMDb, Metacritic e Rotten Tomatoes.
Supporta rotazione automatica in caso di rate limit. Compatibile con configurazione a chiave singola.
Ottieni la tua API key gratuita su omdbapi.com/apikey.aspx (richiede verifica email)

Database Postgres

Connessione obbligatoria: inserisci host, porta, user e nome DB.
Password via ENV/Secret.

CLI: export OCTOHUB_DB_PASSWORD="password"
URL completa: export OCTOHUB_DB_URL="postgresql+psycopg2://utente:password@host:5432/db"
Configura il container Postgres in Docker e inserisci qui le credenziali del servizio.
